# EZEE VISION COURSE HUB — Phase 1

Premium mobile-first course catalogue UI built with Next.js.

## Phase 1 includes
- Premium dark course-hub UI
- Responsive mobile/tablet/desktop layout
- Search UI
- Category pills
- Course cards
- `+ ENROLL` visual state
- `LET'S STUDY` visual button
- Enrolled section placeholder
- FAQ
- Vercel-ready Next.js structure

## Phase 2 plan
Connect Firebase Authentication + Firestore and make enrollment persistent.

## Local development
```bash
npm install
npm run dev
```

Then open:
http://localhost:3000
