# Sayeed Courses Hub — Phase 3

Premium mobile-first course catalogue with dedicated course detail pages.

## Phase 3 includes
- Everything from Phase 2
- `Sayeed Courses Hub` branding
- Dedicated `/course/[id]` detail pages
- Course overview
- What you will learn
- Modules and lessons section
- Course information panel
- Course stats
- Detail-page Enroll / Let's Study UI
- Mobile responsive detail layout
- Shared course data file for easier future Firebase migration

## Not yet connected
- Firebase Authentication
- Persistent enrollment
- Admin panel
- Telegram private-course access

Those are intentionally reserved for later phases.

## Local development
```bash
npm install
npm run dev
```

Then open:
http://localhost:3000
