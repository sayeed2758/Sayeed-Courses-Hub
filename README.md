# EZEE VISION COURSE HUB — Phase 2

Premium mobile-first course catalogue with live client-side interactions.

## Phase 2 includes
- Everything from Phase 1
- Live course search
- Live category filtering
- Instant result count
- Reset filters / empty state
- Featured courses section
- Active/inactive course concept
- Responsive catalogue
- Course action feedback without fake persistence

## Not yet connected
- Firebase Authentication
- Persistent enrollment
- Admin panel
- Telegram course access

Those are intentionally reserved for later phases.

## Local development
```bash
npm install
npm run dev
```

Then open:
http://localhost:3000
